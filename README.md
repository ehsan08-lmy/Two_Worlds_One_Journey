# Two Worlds, One Journey

A 3-page responsive front-end midterm project for Web Technologies 1.

## Pages
- `index.html` — Home / introduction
- `roots.html` — My Roots
- `journey.html` — My Journey + interactive message form

## Technologies
- Semantic HTML5
- CSS3
- Flexbox
- CSS Grid
- Custom media queries
- Bootstrap 5.3
- Google Fonts
- Small JavaScript interaction for the form

## Design idea
The website presents a personal journey between two worlds. The visual language uses warm paper tones, sage green, clay accents, circular route motifs and editorial typography to make the three pages feel like one continuous story.

## Deployment
The project is ready for GitHub Pages.
